# Pitchroom

Singing practice on your own computer. Add a song and Pitchroom splits it into its parts (vocals, drums, bass and the rest), finds its melody and lyrics, and lets you sing along: the singer's notes scroll past, your own pitch is drawn over them, and a phrase can be looped until it sits. Takes can be recorded and listened back to.

This repository holds the installers only. **Download the latest from [Releases](https://github.com/freaktion-craft/pitchroom-releases/releases/latest).** The code is in [pitch-room](https://github.com/freaktion-craft/pitch-room).

| System | File |
|---|---|
| macOS, Apple silicon | `Pitchroom-…-mac-arm64.dmg` |
| macOS, Intel | `Pitchroom-…-mac-x64.dmg` |
| Windows | `pitchroom_install.exe` |

## Opening it the first time

The app isn't signed yet, so the system asks once:

- **macOS:** open it, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Windows:** at "Windows protected your PC", click **More info → Run anyway**.

The first song needs the tools that split songs and read their melody and lyrics (3–4 GB, downloaded once). Everything stays on your computer: your songs, takes and settings are kept in Pitchroom's own folder (**Help → Open Data Folder**).

Pitchroom looks for a new version as it opens, and updates itself.

> **For personal practice only.** Use audio you have the right to use.
